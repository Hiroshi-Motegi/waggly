# 練習記録カレンダーUI デザインスペック

## 概要

練習記録一覧ページを、現在のフラットなリスト表示から iPhoneカレンダー風のカレンダー+リスト表示に刷新する。練習頻度の可視化と日付ベースのナビゲーションにより、練習記録へのアクセス体験を向上させる。

## Figma

https://www.figma.com/design/thCsjskQb7stnOqr2uglTZ/waggly?node-id=59-5662

## 対象ページ

`/practice` — 練習記録一覧ページ（`src/app/practice/page.tsx`）

## 表示モード

カレンダー表示とリスト表示の2モードを右上アイコンで切り替える。

- **カレンダー表示**: 本スペックのメイン。カレンダー + 日付グルーピングリスト
- **リスト表示**: 現在の実装をそのまま維持。フラットなセッション一覧

デフォルトはカレンダー表示。

## カレンダー表示モード

### ヘッダー

- 左: 「練習記録」タイトル（白文字、緑背景）
- 右: 「+ 記録する」ボタン → `/practice/new` へ遷移

### カレンダー部分

#### レイアウト

- 月間カレンダー、月曜始まり
- **6行固定**で高さを確保（月によって4〜6週あるが、常に6行分の高さを取ることでリスト部分がガタつかない）
- 前月・翌月にはみ出す日付はグレーテキストで表示

#### 年月表示・ナビゲーション

- 左上に「2026年6月 ∨」と表示
- タップで**月ピッカー**を表示（年月を選択して任意の月にジャンプ）
- 右上にアイコン2つ:
  - カレンダーアイコン（アクティブ状態）
  - リストアイコン → リスト表示モードに切り替え

#### スワイプナビゲーション

- カレンダー領域を**上スワイプ → 翌月**、**下スワイプ → 前月**に移動
- アニメーション付きで方向感を出す（スライドトランジション）
- touch イベントで実装（タッチ開始・終了のY座標差で判定）

#### 日付マーカー

3つの状態を視覚的に区別する:

| 状態 | スタイル |
|------|---------|
| 今日 | 黄色背景の丸 |
| 練習した日 | 白背景の丸 |
| 選択中の日 | 緑の枠線（ring） |
| 今日 + 選択中 | 黄色背景 + 枠線（両方適用） |
| 練習日 + 選択中 | 白背景 + 枠線（両方適用） |
| 通常の日 | スタイルなし（暗い背景にグレーテキスト） |

#### 「今日」ボタン

- 月を移動した後に表示される
- タップで今日の日付を含む月に戻り、今日を選択状態にする
- 今日の月を表示中は非表示

### セッションリスト（カレンダー下部）

#### 表示ルール

- 選択した日付から**過去方向に日付降順**でセッションを表示
- 同じ月のセッションを表示（選択月内のデータ）
- 日付でグルーピング:
  - 最初のセッション: 左に日付バッジ（日 + 曜日、例: `14 金`）
  - 同日の2件目以降: 日付バッジなし、インデントで揃える

#### カード内容

各セッションカードに表示する情報:

1. **場所**（太字）— 未入力の場合は「場所未入力」
2. **球数バッジ**（右端）— 例: `100球`、未入力の場合は非表示
3. **★評価** — あれば星表示（例: ★★★☆☆）、なければ非表示
4. **メモ冒頭** — あれば2行clampで表示、なければ非表示

カードタップで `/practice/[sessionId]` 詳細ページへ遷移。

#### 空状態

- **選択日以降に記録がない場合**: 「練習記録がありません」メッセージ
- **月全体で練習ゼロの場合**: 「今月の練習: 0回」 + 「記録する」ボタンへの導線

## データ取得

### 既存API

- `GET /api/practice` — 全セッション取得（現在は直近20件）

### 変更が必要な点

- APIにクエリパラメータを追加: `GET /api/practice?month=2026-06` で月指定取得
- `month` パラメータなしの場合は従来通り直近20件を返す（リスト表示モード互換）
- レスポンスから `practiced_at` を抽出してカレンダーの練習日マーカーに使用

## コンポーネント構成

```
PracticePage
├── PageHeader（「練習記録」+ 「+ 記録する」）
├── ViewToggle（カレンダー/リスト切り替えアイコン）
├── [カレンダー表示モード]
│   ├── MonthCalendar
│   │   ├── MonthYearHeader（「2026年6月 ∨」+ 月ピッカー）
│   │   ├── WeekdayHeader（月火水木金土日）
│   │   ├── CalendarGrid（6行 × 7列の日付セル）
│   │   │   └── DayCell（日付マーカー: today/practiced/selected）
│   │   └── TodayButton（月移動後に表示）
│   └── SessionList
│       └── DateGroup
│           ├── DateBadge（14 金）
│           └── SessionCard（場所 + 球数 + 評価 + メモ）
└── [リスト表示モード]
    └── 現在の実装をそのまま使用
```

## 技術メモ

- スワイプ検知: `touchstart` / `touchend` イベントのY座標差で判定。閾値は50px程度
- カレンダー高さ固定: 6行 × セル高さで `min-height` を設定
- 月ピッカー: ドロップダウンモーダルで年月選択。年はボタンで前後切り替え、月は12個のグリッドボタンで選択
- 状態管理: `useState` で選択日・表示月・表示モードを管理。URL パラメータとの同期は不要（画面遷移で状態リセットでOK）
