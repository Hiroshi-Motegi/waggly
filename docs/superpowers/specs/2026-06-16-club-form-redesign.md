# クラブ登録フォーム再設計

## 概要

クラブ登録・編集フォームの情報階層を見直し、ゴルファーが実用的に把握する情報を基本情報に昇格。シャフト名・フレックス・グリップ名・ロフト角・総重量・バランス・長さを基本情報に含め、詳細項目はアコーディオンに整理する。AI自動入力は基本情報の入力値（シャフト名含む）を元に検索し、未入力のスペック項目を埋める。

## 現状の構成

1. 基本情報（常時表示）: 種類、番手、メーカー、モデル、評価
2. 購入情報（アコーディオン）
3. シャフト（アコーディオン）: シャフト名、フレックス、シャフト重量、キックポイント
4. グリップ（アコーディオン）: グリップ名、グリップ太さ
5. ヘッドスペック（アコーディオン）: ロフト角、ライ角、長さ、ヘッド重量、バウンス、ソール形状、フェース角、ヘッド体積
6. 全体スペック（アコーディオン）: 総重量、バランス

## 変更後の構成

### 基本情報（常時表示）

- 種類、番手（既存）
- メーカー、モデル（既存）
- シャフト名、フレックス（シャフトセクションから昇格）
- グリップ名（グリップセクションから昇格）
- ロフト角（ヘッドスペックから昇格）
- 総重量、バランス（全体スペックから昇格）
- 長さ（ヘッドスペックから昇格）
- 評価（既存）

### AI自動入力ボタン（基本情報の下）

- 基本情報の入力値（メーカー、モデル、番手、シャフト名、フレックス）をWeb検索のクエリに使用
- シャフト名が入力されていれば検索精度が向上（重量等がシャフト依存のため）
- 未入力のスペック項目（ロフト角、総重量、バランス、長さ + 詳細アコーディオン内の項目）を自動入力
- ユーザーが既に入力した値は上書きしない（既存動作のまま）

### 購入情報（アコーディオン）

既存のまま: 発売年、購入日、購入店、価格

### シャフト詳細（アコーディオン）

- 上部にシャフト名・フレックスをテキスト表示（基本情報で入力した値を参照表示）
- シャフト重量
- キックポイント

### ヘッドスペック（アコーディオン）

ロフト角・長さを除いた残り:
- ライ角
- ヘッド体積
- ヘッド重量
- バウンス（ウェッジ用）
- ソール形状（ウェッジ用）
- フェース角（ドライバー用）

### グリップ詳細（アコーディオン）

- 上部にグリップ名をテキスト表示（基本情報で入力した値を参照表示）
- グリップ太さ

## 設計ポイント

### 情報階層の基準

- **基本情報**: ゴルファーが「自分のクラブを一言で説明できる」情報。中古売買、仲間との比較、リシャフト検討で参照する項目
- **詳細アコーディオン**: こだわる人が記録する追加スペック。なくても困らないがあると嬉しい

### 詳細アコーディオンの参照表示

シャフト詳細・グリップ詳細のアコーディオン上部に、基本情報で入力した値を読み取り専用テキストとして表示する。これにより：
- アコーディオンを開いた時に「何のシャフト/グリップの詳細を入力しているか」が分かる
- 編集は基本情報側で行う（二重管理にならない）

### AI自動入力の検索クエリ改善

基本情報にシャフト名が含まれることで、検索クエリが充実:
```
現在: "PING G440 6I番 アイアン スペック ロフト角 ライ角 長さ"
改善: "PING G440 6I番 アイアン AWT 3.0 LITE S スペック ロフト角 ライ角 長さ 重量"
```

シャフト名+フレックスが入ると総重量・バランスの精度が上がる。
