# クラブ登録フォーム再設計

## 概要

クラブ登録・編集フォームの情報階層を見直し、ゴルファーが実用的に把握する情報を基本情報に昇格。シャフト名・フレックス・ロフト角・総重量・バランス・長さを基本情報に含め、詳細項目はアコーディオンに整理する。AI自動入力は基本情報の入力値（シャフト名含む）を元に検索し、未入力のスペック項目を埋める。

## 現状の構成

1. 基本情報（常時表示）: 写真、種類、番手、メーカー、モデル、評価
2. 購入情報（アコーディオン）
3. スペック自動入力ボタン
4. シャフト（アコーディオン、パター非表示）: シャフト名、素材、フレックス、シャフト重量、振動数、キックポイント
5. グリップ（アコーディオン）: グリップ名、グリップ太さ
6. ヘッドスペック（アコーディオン）: ロフト角、ライ角、長さ、ヘッド重量、バウンス、ソール形状、フェース角、ヘッド体積
7. 全体スペック（アコーディオン）: 総重量、バランス

## 変更後の構成

### 基本情報（常時表示）

- 写真（既存）
- 種類、番手（既存）
- メーカー、モデル（既存）
- シャフト名、素材、フレックス（シャフトセクションから昇格、パター時は非表示）
- ロフト角（ヘッドスペックから昇格）
- 総重量、バランス（全体スペックから昇格）
- 長さ（ヘッドスペックから昇格）
- 評価（既存）

※ 素材セレクタはフレックスの選択肢を切り替えるため（カーボン: X/S/SR/R/R2/L、スチール: X100/S400等）、フレックスとセットで昇格する

### AI自動入力ボタン（基本情報の直下、購入情報の上）

現状は購入情報の下にあるが、基本情報の直下に移動する。基本情報を入力→自動入力で残りを埋める→結果を確認して詳細へ、という自然な流れにするため。

- 基本情報の入力値（メーカー、モデル、番手、シャフト名、フレックス）をWeb検索のクエリに使用
- シャフト名が入力されていれば検索精度が向上（重量等がシャフト依存のため）
- 未入力のスペック項目（ロフト角、総重量、バランス、長さ + 詳細アコーディオン内の項目）を自動入力
- ユーザーが既に入力した値は上書きしない（既存動作のまま）

### 購入情報（アコーディオン）

既存のまま: 発売年、購入日、購入店、価格

### シャフト詳細（アコーディオン、パター時は非表示）

- 上部にシャフト名・素材・フレックスをテキスト表示（基本情報で入力した値を参照表示）
- シャフト重量
- 振動数
- キックポイント

### ヘッドスペック（アコーディオン）

ロフト角・長さを除いた残り:
- ライ角
- ヘッド体積
- ヘッド重量
- バウンス（ウェッジ用）
- ソール形状（ウェッジ用）
- フェース角（ドライバー用）

### グリップ（アコーディオン）

既存のまま: グリップ名、グリップ太さ
（グリップ名はショップ商品ページやメーカー公式スペック表の主要項目ではなく、交換前提の付属品扱いのため基本情報には含めない）

## 設計ポイント

### 情報階層の基準

- **基本情報**: ゴルファーが「自分のクラブを一言で説明できる」情報。中古売買、仲間との比較、リシャフト検討で参照する項目
- **詳細アコーディオン**: こだわる人が記録する追加スペック。なくても困らないがあると嬉しい

### パター時の表示ルール

パターではシャフト関連（シャフト名、素材、フレックス）を基本情報・シャフト詳細ともに非表示とする（現状の動作を維持）。

### 詳細アコーディオンの参照表示

シャフト詳細のアコーディオン上部に、基本情報で入力した値を読み取り専用テキストとして表示する。これにより：
- アコーディオンを開いた時に「何のシャフトの詳細を入力しているか」が分かる
- 編集は基本情報側で行う（二重管理にならない）

### 昇格項目の選定基準

中古ショップの商品ページ（Golf Do等）やメーカー公式スペック表に標準的に掲載される項目を基本情報とする。グリップ名は交換前提の消耗品であり、ショップ商品ページのスペック欄には載らないため詳細アコーディオンに留める。

### AI自動入力の検索クエリ改善

基本情報にシャフト名が含まれることで、検索クエリが充実:
```
現在: "PING G440 6I番 アイアン スペック ロフト角 ライ角 長さ"
改善: "PING G440 6I番 アイアン AWT 3.0 LITE S スペック ロフト角 ライ角 長さ 重量"
```

シャフト名+フレックスが入ると総重量・バランスの精度が上がる。

### 昇格項目の入力UI

基本情報に昇格するスペック項目（ロフト角、総重量、バランス、長さ）は、既存の基本情報フィールド（全幅テキスト入力）と同じレイアウトにする。現状の `SpecRow`（右寄せ100px + 単位）形式ではなく、ラベル+全幅入力+単位テキストの形式に統一する。
