# アカウント連携ヘルプページ & ヘルプINDEX

## 概要

アカウント連携が「なぜ必要か」をユーザーに伝えるヘルプページを作成する。設定画面にヘルプINDEXへの導線と、アカウント連携セクションから直接ヘルプへの導線を追加する。

## 背景

- AndroidアプリはGoogleアカウント、将来のiOSアプリはApple IDがクラウド同期に必須
- Web版はLINEログインが多い → クロスプラットフォーム利用にはアカウント連携が必要
- 現状の設定画面にはこの説明がなく、ユーザーが「なぜ連携するのか」を理解できない

## ページ構成

### 1. アカウント連携ヘルプページ (`/help/account-linking`)

一枚まとめ + FAQ 形式。上から順に:

#### 概要テキスト
> Wagglyはクラウド同期により、Webブラウザとスマホアプリで同じデータを使えます。
> アプリで同期するには、各プラットフォームに対応したアカウントの連携が必要です。

#### 対応表

| プラットフォーム | 同期に必要なアカウント |
|---|---|
| 🌐 Webブラウザ | どれでもOK |
| 🤖 Androidアプリ | Google必須 |
| 🍎 iOSアプリ | 準備中 |

#### こんなときは（シナリオ）

- **LINEで利用中 → Androidアプリで同期したい** → 設定からGoogle連携を追加
- **Googleで利用中 → Web版でLINEログインしたい** → 設定からLINE連携を追加

#### FAQ

- **Q: 連携するとデータはどうなる？** → 今のデータはそのまま残る。別のログイン方法を追加するだけ。
- **Q: 連携先にすでにアカウントがある場合は？** → どちらのデータを残すか選べる画面が表示される。選ばなかった方のデータは削除。
- **Q: 連携を解除したらどうなる？** → そのログイン方法が使えなくなるだけでデータは残る。最低1つのログイン方法は必要。

### 2. ヘルプINDEXページ (`/help`)

ヘルプトピックの一覧ページ。現時点のエントリ:
- アカウント連携について → `/help/account-linking`

今後トピック追加時にここにリンクを増やす。

## 導線

### 導線1: アカウント連携セクション → 直接ヘルプへ

設定画面の「アカウント連携」テキスト見出しの右に「?」アイコンを配置。タップで `/help/account-linking` に直接遷移。

```
アカウント連携           [?]   ← ここ
┌─────────────────────────┐
│ LINE         連携済み    │
│ Google       連携する    │
└─────────────────────────┘
```

### 導線2: 法的情報カード → ヘルプINDEX

既存の利用規約・プライバシーポリシーのカードに「ヘルプ」行を追加。タップで `/help`（INDEXページ）に遷移。

```
┌─────────────────────────┐
│ 利用規約              › │
│ プライバシーポリシー    › │
│ ヘルプ                › │   ← 追加
└─────────────────────────┘
```

## スコープ

- LINE + Google のみ（Apple IDは将来iOS対応時に追加）
- Android版はWebViewでこのヘルプページを表示（ネイティブ実装不要）
