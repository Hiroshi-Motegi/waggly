Waggly USP戦略 — 3つのアプローチ

「ギア管理 × シェア × AI」の隙間ソリューション。どの順番で攻めるか？

A

ギアファースト戦略

コア: クラブ管理を業界最高にする → シェアで広がる → AIで定着


Phase 1: ギアマネ超え（WITBビジュアル、重量フロー、飛距離階段、メンテ履歴）

Phase 2: ライトシェア（QRコード名刺、友達のバッグ閲覧）

Phase 3: AIギア相談 + アフィリエイト導線


Pros

  • ギアマネユーザーを直接狙える
  • 管理ツールは口コミで広がりやすい
  • データが溜まってからAIが活きる

Cons

  • 初期の差別化がギアマネとの機能勝負になる
  • AIの強みが後回し
  • 収益化まで時間がかかる
B

シェアファースト戦略

コア: 「名刺交換」体験で広がる → ギア管理で定着 → AIで課金


Phase 1: ゴルファーカード（公開プロフィール + QRシェア + セッティング一覧）

Phase 2: ギア管理強化（ライフサイクル、ビジュアル、外部連携）

Phase 3: AIコーチ + アフィリエイト


Pros

  • バイラル性が最も高い（ゴルフ場で見せる→即登録）
  • LINEとの相性抜群（LIFF内でシェア）
  • ゴルフ特有の「何使ってる？」文化にフィット

Cons

  • カード作るだけで離脱するリスク
  • 管理ツールとしての深さが後回し
  • 既存のゴルファーカード設計（docs）を活かせるが、まだ未実装
C

AI × ギア融合戦略（推奨）

コア: ギア管理 + AIを同時に磨く → シェアで広がる → アフィリエイトで収益化


Phase 1: ギア管理強化 + AIギア相談（「次何買う？」「セッティング診断」）を同時投入

Phase 2: ゴルファーカード + QRシェア（バイラル装置）

Phase 3: 外部連携 + アフィリエイト + プレミアム課金


Pros

  • ギアマネにない「AI」が初日から差別化ポイント
  • クラブ登録 → 即AIに相談、の体験が強い
  • 既存のAIコーチ資産をギア方面に転用できる
  • 「管理するだけ」じゃなく「相談できる」が刺さる

Cons

  • Phase 1の開発範囲が広い
  • AI精度の検証が並行で必要
